# Сборка CarrierSIM для iPhone

Готовые IPA уже содержат нативный код ARM64. Для повторной сборки доступны Linux и macOS. Приложение допускает запуск на iOS 26 и новее; создание сопряжения без компьютера рассчитано на iOS 27; установка всё равно требует подписи Apple и подходящего профиля.

## Linux: повторение проверенной сборки

Проверенная среда: Ubuntu 24.04 x86_64. Нужны Python 3, Git, curl, `dpkg-deb`, `make`, C-компилятор и обычные системные библиотеки Ubuntu. На чистой Ubuntu зависимости устанавливаются так:

```bash
sudo apt-get update
sudo apt-get install -y python3 git curl ca-certificates dpkg-dev build-essential xz-utils libedit2 libffi8 libxml2 libzstd1 libtinfo6 zlib1g
```

Из корня распакованного проекта запусти:

```bash
bash scripts/setup-linux.sh --build
```

Скрипт скачивает компиляторы в каталог `../toolchain`, проверяет контрольные суммы и запускает сборку. Он не меняет системные пакеты, профиль shell или текущую установку Rust. Первый запуск требует интернета и нескольких гигабайт свободного места с учётом кэша зависимостей и промежуточных файлов. Повторный запуск использует скачанные файлы.

Закреплены LLVM/Clang/LLD 20.1.8, Rust 1.98.1, `aarch64-apple-ios`, ldid 2.1.5-procursus7 и конкретная ревизия SDK из Theos. Полные версии, адреса и SHA-256 находятся в `scripts/linux-toolchain.json`. Каталог SDK называется `iPhoneOS16.5.sdk`, но его собственный `SDKSettings.json` сообщает версию 16.4; компилятор использует эту фактическую версию. Минимальная версия приложения в `Info.plist` равна 26.0.

Если инструменты уже установлены этим скриптом, повторная сборка выполняется одной командой:

```bash
bash scripts/build-linux.sh
```

Для другого расположения инструментов и собственного SDK доступны явные пути:

```bash
CARRIERSIM_TOOLCHAIN=/absolute/path/to/toolchain SDKROOT=/absolute/path/to/iPhoneOS.sdk bash scripts/build-linux.sh
```

При использовании отдельной установки LLVM можно дополнительно указать `LLVM_ROOT` или `LLVM_BIN`. В `PATH` должны быть `clang`, `clang++`, `ld64.lld`, `llvm-ar`, `llvm-nm`, Rust/Cargo и `ldid`. Rust и iOS SDK не включены в архив исходников.

## macOS

Нужны полная установленная Xcode с iPhoneOS SDK, выбранная через `xcode-select`, Rust через rustup и Python 3. После этого из корня проекта:

```bash
bash scripts/build-macos.sh
```

Скрипт сам добавит цель Rust `aarch64-apple-ios`, соберёт приложение и расширение через `xcrun` и упакует обе версии. Дополнительный генератор Xcode-проекта не требуется. Этот скрипт проверен на синтаксис; фактическая сборка предоставленных IPA выполнена в Linux.

## Результаты

- `build/CarrierSIM-iOS-unsigned.ipa` — приложение со встроенным локальным VPN-расширением.
- `build/CarrierSIM-iOS-external-vpn.ipa` — тот же интерфейс и движок, без VPN-расширения и его entitlement; использует внешний LocalDevVPN.
- `build/CarrierSIM-build-manifest.json` — версии компиляторов, SHA-256 входных файлов и обоих IPA.

Оба IPA имеют одинаковый Bundle ID и представляют альтернативные варианты установки. Основной вариант содержит всё доступное внутри приложения. Вариант с внешним VPN нужен, если используемая подпись не допускает Network Extension.

Встроенная ad-hoc подпись сохраняет entitlement `packet-tunnel-provider` и позволяет проверить структуру бинарников. Она не является установочной подписью Apple. Для основного IPA подпиши и приложение, и вложенное расширение профилями, допускающими Network Extension. Внешний вариант не запрашивает этот entitlement. Pairing-файлы и пользовательские ключи при сборке не нужны.

## Проверки

Linux-сборка проверяет формат Mach-O, ARM64, исполняемый тип обеих программ, обязательные экспортированные функции, права исполняемых файлов, целостность ZIP и отсутствие сетевого entitlement во внешнем варианте. Снимок исходников запрещает завершение сборки, если файлы изменились во время компиляции: в этом случае запусти сборку снова.

Дополнительная проверка готовых файлов из корня проекта:

```bash
python3 Tests/verify_package.py build/CarrierSIM-iOS-unsigned.ipa
python3 Tests/verify_package.py build/CarrierSIM-iOS-external-vpn.ipa --external-vpn
```

ThinLTO отключён для Linux и macOS: в использованной версии LLVM/Rust он мог создавать пустые промежуточные Mach-O объекты. Обычная оптимизация release и удаление неиспользуемого кода линкером включены. `CARRIERSIM_SKIP_RUST=1` предназначен только для быстрой правки интерфейса с уже собранным неизменённым Rust-кодом; финальную сборку выполняй без этого параметра.
