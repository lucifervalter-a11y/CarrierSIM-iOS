# CarrierSIM для iOS

**ОРИГИНАЛ CARRIERSIM ВЗЯТ ИЗ [IOS-BUNDLES/CARRIERSIM](https://github.com/ios-bundles/CarrierSIM).**

Нативное приложение CarrierSIM 1.1 для iPhone с iOS 26 и новее. Создание Remote Pairing без компьютера рассчитано на iOS 27; на iOS 26 требуется готовый файл сопряжения. Перенос CarrierSIM v4 из предоставленного архива: интерфейс на русском, сопряжение на самом телефоне, локальный VPN, выбор SIM, смена профиля оператора, возврат штатного выбора и восстановление прерванных операций.

**Это экспериментальная сборка.** Компиляция и автоматические проверки не заменяют запуск на физическом iPhone. Работу этой сборки на конкретном устройстве необходимо проверить. Исходный CarrierSIM заявлял проверку на iPhone 17 с iOS 27.0; для других сборок iOS совместимость не подтверждается автоматически.

## Другой iPhone и установка по Wi-Fi

1. Подключите оба iPhone к одной Wi-Fi-сети. Разрешите CarrierSIM доступ к локальной сети. Гостевая сеть с изоляцией клиентов не подходит.
2. Откройте **«Выбранный iPhone» → «Другой iPhone»**. Можно найти службы Apple через Bonjour или указать IPv4-адрес из настроек Wi-Fi телефона друга. Порт 49152 — исходное значение для локального туннеля, а не гарантия порта службы другого телефона. Для сетевого соединения нужен фактический порт `_remoted._tcp` или `_remotepairing._tcp`.
3. Создайте сопряжение в CarrierSIM. **Друг подтверждает код в настройках своего iPhone**, код отображается на вашем телефоне. Либо импортируйте pairing-файл именно телефона друга. На iOS 26 создание сопряжения через настройки не предусмотрено этим механизмом: нужен заранее полученный файл.
4. Найдите актуальные адрес и порт службы друга после сопряжения, если они изменились. Разблокируйте его телефон и нажмите **«Проверить iPhone»**. Проверьте имя и модель в результате.
5. Для смены профиля выберите SIM, профиль, повторите проверку и примените его. Для установки приложения выберите **«Установить подписанный IPA другу»** и готовый файл `.ipa`.

Ключи и резервные копии другого iPhone хранятся в отдельном защищённом каталоге `CarrierSIM/remote`. Ключи вашего телефона сохраняются в прежнем месте. После изменения адреса, сопряжения или режима проверка сбрасывается. Сетевой транспорт не использует локальный VPN как запасной адрес друга; перед записью и установкой проверяется SHA-256 идентификатора ранее проверенного устройства. Журналы восстановления дополнительно привязаны к идентификатору самого iPhone.

**Установка требует подписи для iPhone друга.** Этот выпуск передаёт IPA через AFC в `PublicStaging` и вызывает системную службу InstallationProxy. Он не выдаёт сертификаты Apple и не подписывает IPA через Apple Account. Наличие `embedded.mobileprovision` и ресурсов подписи проверяется для приложения и каждого расширения; это предварительная проверка структуры, а не доказательство действительности подписи. Подпись, срок действия, разрешения и допустимое устройство проверяет iOS. Успех отображается после подтверждения InstallationProxy и появления Bundle ID в списке установленных приложений.

Если платный сертификат DDE Store привязан только к вашему UDID, другу потребуется его собственная регистрация и подходящий подписанный IPA. Встроенный VPN также требует разрешённых профилей для приложения и расширения; иначе используйте вариант с внешним VPN. Запрос установки по сети не переносит ваш сертификат автоматически и не обходится без проверки iOS. Временный IPA удаляется после попытки; при потере связи остаток в `PublicStaging` может остаться, о чём будет запись в журнале.

**Прямое соединение iPhone → iPhone по Wi-Fi пока экспериментальное.** На реальных телефонах оно в этой среде не проверено. iOS может не публиковать нужные службы или не разрешать доступ к ним из обычной LAN. Если поиск пуст или соединение не проходит после проверки адреса, порта и ключей, рабочий запасной путь — установить CarrierSIM непосредственно на телефон друга через его сервис подписи и выбрать «Этот iPhone». LocalDevVPN на вашем телефоне открывает службы вашего телефона и не делает службы друга доступными.

Механизм [SideInstaller](https://github.com/FrizzleM/SideInstaller) изучен как справочный: он включает отдельные этапы сопряжения, подписи через Apple Account и установки. Его приложение, IPAs и механизм авторизации Apple не встроены в CarrierSIM. Установка здесь реализована поверх имеющейся библиотеки idevice.

## Если «Режим разработчика» не появляется

Apple описывает это условие в [официальной инструкции](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device): пункт появляется после начала сопряжения либо после прежнего сопряжения с Mac. Установка через платный сертификат сама по себе не гарантирует появление пункта.

Если настройки не показывают этот пункт и файла сопряжения нет, подготовьте телефон через совместимый Mac/компьютер и подтвердите доверие на самом iPhone. Для пути Apple используйте Xcode / Device Hub. Импорт файла сопряжения в CarrierSIM не включает режим разработчика автоматически и не доказывает, что службы доступны по Wi-Fi. Действия и перезагрузку, которые запрашивает iOS, выполняет владелец телефона.

## Можно ли подключить два iPhone кабелем USB-C

В версии 1.1 транспорт iPhone → iPhone через USB-C не реализован. Кабель сам по себе не превращает ваш iPhone в компьютер с доступом к службам установки и настройки другого iPhone. Прямое управление профилем без установки CarrierSIM другу предусмотрено через LAN, но для него нужно разрешённое iOS сопряжение и доступные службы устройства. Если они отсутствуют, приложение не может завершить подготовку друга одним нажатием.

## 5G, iPhone 12+, Yota и t2

[iPhone 12 и новее поддерживают 5G аппаратно](https://support.apple.com/108383). Это относится к вашим iPhone 17 Pro Max и iPhone 16 Plus. Приложение может изменить выбор системного профиля оператора, но не может создать сеть 5G, добавить поддержку в SIM, включить услугу у оператора или гарантировать связь на всех моделях.

После применения профиля на целевом телефоне откройте **Настройки → Сотовая связь → выбранная SIM → Параметры данных → Голос и данные**. Если доступно, выберите **5G автоматически** или **5G вкл.** Проверьте у Yota или t2, доступен ли настоящий 5G для этой SIM, тарифа и места использования. Появление пункта меню или значка не является измерением подключения к NR; скорость также сама по себе не доказывает 5G. Этот выпуск не содержит подтверждённого универсального профиля для Yota/t2 и не заявляет, что у этих операторов есть коммерческое покрытие в вашем городе.

Установка CarrierSIM на iOS 26 разрешена метаданными пакета, но работа метода смены профиля на iOS 26, всех iPhone 12+ и последних бетах iOS 27 не подтверждена. Снижение `MinimumOSVersion` не исправляет возможные изменения протоколов и метода записи. Перед применением нужны успешная диагностика, сохранённая копия и проверка связи на конкретном телефоне.

## Какие IPA предусмотрены

| Файл | Для чего |
|---|---|
| `CarrierSIM-iOS-unsigned.ipa` | Основной вариант: приложение и встроенный локальный VPN. |
| `CarrierSIM-iOS-external-vpn.ipa` | Запасной вариант без VPN-расширения: для сервисов подписи, которые не поддерживают Network Extension. Нужен отдельно установленный LocalDevVPN. |

Оба файла нужно подписать своим способом установки IPA. В пакете нет сертификата Apple и профиля установки для вашего устройства. Техническая ad-hoc подпись сохраняет структуру и шаблон разрешений; сама по себе она не разрешает установку на обычный iPhone.

Для основного варианта подпись должна включать приложение **и вложенное расширение** и разрешение `com.apple.developer.networking.networkextension = [packet-tunnel-provider]` в подходящих provisioning profiles. Если сервис удаляет расширения или не предоставляет это разрешение, используйте запасной вариант. Приложение проверяет наличие встроенного расширения и показывает доступный способ подключения.

## Первый запуск

1. Подпишите и установите выбранный IPA.
2. В CarrierSIM нажмите **«Сопряжение с iPhone» → «Создать сопряжение»**. Разрешите локальную сеть и уведомления: в уведомлении появится код.
3. Откройте настройки iOS: **Конфиденциальность и безопасность → Режим разработчика**. Включите режим разработчика, если он выключен; выполните перезагрузку, если её предлагает iOS. Начните сопряжение с CarrierSIM, подтвердите код и вернитесь в приложение. Если режим пришлось включать с перезагрузкой, начните создание сопряжения заново.
4. Нажмите **«Локальное подключение» → «Включить встроенный VPN»** и подтвердите системное разрешение. В запасной сборке используйте кнопку LocalDevVPN.
5. Нажмите **«Проверить iPhone»**. Эта проверка читает сведения и SIM, не меняя профиль оператора.
6. Выберите нужную SIM и профиль. По умолчанию указан `Vodafone_hu`, как в исходном архиве. После изменения выбора снова проверьте iPhone, затем нажмите **«Применить профиль»**.
7. Оставьте CarrierSIM открытым до результата. Не выключайте локальный VPN во время записи.

Сопряжение, ресурсы и резервные копии сохраняются автоматически. Повторно искать Python, iTunes, библиотеки и файлы IPCC не нужно. Системные подтверждения iOS приложение выполнить за пользователя не может.

### Если Stik Pair уже использовался

Кнопка **«Уже есть файл Stik Pair»** позволяет импортировать Remote Pairing `.plist` / `.rppairing` через «Файлы». Поддерживается также полный Lockdown pairing record. Проверка структуры файла выполняется при импорте, а фактическая действительность ключей — при «Проверить iPhone».

Встроенное сопряжение использует тот же протокол Remote Pairing через библиотеку `idevice`. Приложение Stik Pair не упаковано внутрь IPA, и не используется выдуманная схема автоматического обмена файлами.

## Что означают результаты

- **Каталог проверен**: записанные данные независимо прочитаны обратно и совпали с планом.
- **Выбор профиля подтверждён iOS**: в журнале CommCenter обнаружены выбранный пакет и успешная проверка подписи для нужных линий.
- **Выбор пока не подтверждён**: запись могла пройти, но подтверждения iOS недостаточно. Это не сообщение об успешной работе VoWiFi.
- **Есть незавершённая операция**: новая запись блокируется. Сначала запустите восстановление.

Приложение не утверждает, что профиль сам по себе гарантирует VoWiFi, EVS или 5G. Это зависит от оператора, SIM, устройства, версии iOS и поддержки сети.

## Проверка вызовов по Wi-Fi

В настройках iOS откройте **Сотовая связь → нужная SIM → Вызовы по Wi-Fi**. Если переключатель появился, включите его. Для проверки включите авиарежим, затем Wi-Fi, дождитесь отметки Wi-Fi возле оператора и проверьте звонок. После проверки выключите авиарежим.

## Откат и сбои

- **Вернуть штатные профили** удаляет все корневые символьные ссылки, имена которых состоят из 15 цифр IMSI. Это относится ко всем SIM, включая ссылки от ранее установленных карт. Файлы операторов и ссылки MCC/MNC сохраняются.
- **Восстановить после сбоя** использует журнал, точную копию каталога и копии служебных файлов Books. Изменения привязаны к тому же iPhone. Если после сбоя появились другие настройки оператора или новые записи Books, восстановление сохраняет их; при неоднозначном состоянии останавливается с сохранёнными копиями. Незавершённая операция не запускается заново вслепую.
- **Не удаляйте приложение до восстановления**: его удаление удаляет локальные резервные копии. Экспорт диагностического журнала не включает эти копии.
- Если прерывание оставило частично записанный служебный файл и его состояние нельзя однозначно связать с журналом, автоматическое восстановление остановится и сохранит копии. Успешное восстановление после любого возможного сбоя не гарантируется.
- Независимый подписанный IPCC используется как триггер пересканирования, как в исходном CarrierSIM. Он может остаться установленным; возврат IMSI-ссылок не означает удаления этого независимого пакета.
- Если «Книги» активно меняют файлы синхронизации, закройте их, дождитесь окончания загрузок и повторите проверку. Приложение временно использует служебные файлы синхронизации Books; содержимое самих книг не копирует и не редактирует.

## Приватность

Приложение не отправляет данные на внешний сервер, не содержит аналитики и не требует аккаунта. Для работы используются локальные соединения выбранного iPhone; в режиме друга подписанный IPA передаётся этому устройству. Ключи, журналы восстановления и резервные копии находятся в защищённом Application Support, исключённом из резервного копирования приложения в облако. PIN показывается в интерфейсе и локальном уведомлении.

Кнопка экспорта журнала создаёт отдельный текстовый файл. Файлы сопряжения, приватные ключи, содержимое резервных копий и полные IMSI в него не добавляются. Исходные копии сами по себе содержат чувствительные имена SIM-ссылок и должны оставаться личными.

## Состав исходников

| Каталог / файл | Назначение |
|---|---|
| `App/` | UIKit, выбор своего/другого iPhone, поиск Bonjour, импорт pairing/IPA, сопряжение, VPN, Grappa-мост. |
| `rust-core/src/device_target.rs` | Явный LAN-адрес без локального fallback и проверка идентификатора устройства. |
| `rust-core/src/installer.rs` | Проверка структуры подписанного IPA, передача AFC, установка и проверка результата iOS. |
| `Tunnel/` | Встроенный Network Extension, обрабатывающий только локальный адрес `10.7.0.1/32`. |
| `rust-core/src/carrier.rs` | Транзакции записи, проверка привязки к iPhone/SIM, Books и восстановление. |
| `rust-core/src/carrier_data.rs` | Дерево файлов/ссылок, ZIP, ограничения размеров, выбор SIM и проверка ресурсов. |
| `rust-core/src/carrier_trigger.rs` | Загрузка IPCC и наблюдение подтверждения CommCenter. |
| `rust-core/src/carrier_recovery.rs` | Восстановление служебных файлов Books с сохранением более поздних пользовательских изменений. |
| `rust-core/src/pairing.rs` | Встроенное Remote Pairing, ограниченное по времени и отменяемое. |
| `Resources/` | Оригинальные IPCC-ресурсы, исходная настройка по умолчанию и иконки. |
| `Licenses/` | Уведомления и лицензии использованных компонентов. |
| `scripts/` | Сборка и проверка IPA. |
| `Tests/` | Автоматические проверки и протокол проверки сборки. |

В Rust оставлены исходники используемой транспортной библиотеки AirCard/idevice. Интерфейс CarrierSIM вызывает специализированный `cs_execute`; общие функции AirCard для произвольной инъекции каталогов не используются для смены профиля.

## Сборка из исходников

Основная проверенная сборка выполняется на Linux с LLVM, Rust и iPhoneOS SDK. Инструкции и ограничения компоновки приведены в `scripts/BUILDING.md`. Основная команда после настройки инструментов:

```sh
bash scripts/build-linux.sh
```

Результаты находятся в `build/`. Для загрузки полного проекта в ваш GitHub предусмотрен `.github/workflows/build-ios.yml`: он собирает оба IPA, проверяет пакеты и запускает тесты. Workflow подготовлен, но в GitHub в этой сессии не запускался; выходные IPA по-прежнему требуют подписи Apple. Статическая Rust-библиотека компилируется из текущих исходников, а не подменяется готовой библиотекой другой программы. `Cargo.lock` фиксирует зависимости; для перекомпиляции могут понадобиться сетевые загрузки инструментов и зависимостей. На самом iPhone все рабочие ресурсы уже внутри IPA.

Команда запуска тестов Rust, требования к SQLite и результаты проверки пакетов приведены в `Tests/VALIDATION.txt`. Запуск на физическом iPhone и подтверждение операторских функций остаются отдельным этапом.

- [Stik Pair](https://github.com/StikDebug/StikPair): совместимый источник файлов сопряжения; его интерфейс и приложение не копируются в CarrierSIM.

Точные исходные ревизии и контрольные суммы ресурсов приведены в `SOURCE-PROVENANCE.json`.
