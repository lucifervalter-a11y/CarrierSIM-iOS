libplist compatibility headers and test/C++ source attribution

The vendored idevice-ffi/plist.h and the plist_ffi package contain compatibility
headers derived from libplist. The headers retain the original notices,
including these authors:

Copyright (c) 2012-2023 Nikias Bassen, All Rights Reserved.
Copyright (c) 2008-2009 Jonathan Beck, All Rights Reserved.

Their source header states GNU Lesser General Public License version 2.1
or, at the recipient's option, any later version. The complete LGPL 2.1 text
is supplied in LGPL-2.1.txt. Original notices in the supplied source control.

Source: https://github.com/libimobiledevice/libplist
Rust compatibility implementation: https://github.com/jkcoxson/plist_ffi

The upstream plist_ffi README distinguishes the licenses as follows:

"libplist's code (header, C++, tests) are under their original
license. Any code written by me (Rust files) are under MIT OR libplist's license."

The CarrierSIM executable links the Rust plist_ffi crate. It does not build
the separate libplist C++ bindings, C command-line tools, or copied C tests.
The supplied source preserves the relevant compatibility headers and notices.
