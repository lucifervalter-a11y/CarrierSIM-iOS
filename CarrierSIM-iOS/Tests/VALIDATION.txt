CarrierSIM 1.1 — проверка 2026-10-01 UTC

Новая версия: 1.1.0 (2), arm64, MinimumOSVersion 26.0.
Создание Remote Pairing без компьютера рассчитано на iOS 27.

На физическом iPhone эта сборка не запускалась. LAN iPhone → iPhone,
реальная установка, сопряжение с другом, смена операторского профиля,
восстановление на устройстве, работа на iOS 26/последней бете 27 и 5G
для Yota/t2 не подтверждены.

Основной набор Rust: 57 passed, 0 failed. Лог: HOST-TESTS.txt.
Это 49 исходных тестов + 8 новых:
- явный удалённый адрес и отсутствие fallback на свой iPhone;
- запрет публичных/loopback/невалидных адресов;
- запрет записи при смене или отсутствии проверенного идентификатора;
- отказ от IPA без provisioning до подключения к устройству;
- требование provisioning для каждого расширения;
- отказ от обхода путей и нескольких приложений в Payload;
- наличие подписи как структурная проверка, без заявления о её подлинности;
- числовое сравнение минимальной версии iOS.

Дополнительная проверка кандидатов туннеля приведена в TUNNEL-TESTS.txt.
Она проверяет игнорирование loopback, дополнительных адресов и кэша другого
устройства при LAN-соединении.

Лог финальной нативной сборки: NATIVE-BUILD.txt.
Снимок текущих исходников и SHA-256 IPA: BUILD-MANIFEST.json.
Проверка реальной структуры двух IPA: PACKAGE-VERIFICATION.json.

Ограничения:
- Ad-hoc подпись выходных IPA не является установочной подписью Apple.
- Для друга нужен IPA, подписанный для его устройства. Подпись через
  Apple Account внутри этой версии отсутствует.
- Для встроенного VPN нужны профили приложения и расширения с разрешением
  packet-tunnel-provider; иначе используется внешний VPN.
- Проверка наличия mobileprovision/CodeResources не доказывает подлинность.
  Окончательное решение об установке принимает iOS.
- Службы другого iPhone должны быть доступны по LAN. Общая Wi-Fi-сеть
  сама по себе этого не гарантирует. Используются IPv4 и Bonjour; в сети
  только с IPv6 этот режим не предусмотрен.
- iPhone 12+ поддерживают модем 5G, но профиль не создаёт 5G у оператора.
- Установка на iOS 26 допускается пакетом; метод записи профиля на 26
  не подтверждён. Нужен заранее полученный pairing-файл.

Повторение проверки готовых IPA из корня проекта:
python3 Tests/verify_package.py build/CarrierSIM-iOS-unsigned.ipa
python3 Tests/verify_package.py build/CarrierSIM-iOS-external-vpn.ipa --external-vpn

Повторение тестов после настройки toolchain:
CARRIERSIM_TEST_TOOLS="$PWD/../toolchain"
RUSTUP_HOME="$CARRIERSIM_TEST_TOOLS/rustup" \
CARGO_HOME="$CARRIERSIM_TEST_TOOLS/cargo" \
PATH="$CARRIERSIM_TEST_TOOLS/cargo/bin:$PATH" \
LIBRARY_PATH="$CARRIERSIM_TEST_TOOLS/host-native" \
CARGO_TARGET_DIR="$PWD/build/host-tests" CARGO_PROFILE_RELEASE_LTO=false \
cargo test --locked --release --lib --manifest-path rust-core/Cargo.toml

Для отдельной проверки туннеля с теми же переменными:
cargo test --locked --release --manifest-path rust-core/Cargo.toml \
  -p idevice-ffi --lib carrier_sim_lan_tests

В Linux нужен libsqlite3-dev либо приватная ссылка libsqlite3.so на системную
libsqlite3.so.0 в toolchain/host-native. Инструкции сборки — scripts/BUILDING.md.
