# CarrierSIM: опубликованные пакеты

Версия 1.2.1: `CarrierSIM-1.2.1-LAN.zip` — полный комплект, либо выберите `CarrierSIM-1.2.1-unsigned.ipa` (со встроенным VPN) / `CarrierSIM-1.2.1-external-vpn.ipa` (без расширения).

Все публичные IPA требуют подписи Apple для целевого устройства. Импорт P12 и профиля для друга доступен в установленном CarrierSIM 1.2.1. Работа с профилем оператора без установки CarrierSIM другу сохранена. Выпуск экспериментальный, работа на физических iPhone не подтверждена.

Старые пакеты 1.1 и 1.2 сохранены. Хеши всех пакетов — `SHA256SUMS.txt`. Полная инструкция находится в `CarrierSIM-iOS/README.md`, описание версии — в релизе v1.2.1.
