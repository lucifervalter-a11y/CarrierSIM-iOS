# CarrierSIM 1.2.1: вылет экрана режима разработчика

**ОРИГИНАЛ CARRIERSIM ВЗЯТ ИЗ [IOS-BUNDLES/CARRIERSIM](https://github.com/ios-bundles/CarrierSIM).**

При открытии экрана 1.2 автоматически запускал `cs_developer_mode` на GCD-потоке. Сетевой future создавался и выполнялся на его небольшом стеке. Вызов этой публичной функции на потоке со стеком 512 КБ воспроизвёл stack overflow и аварийное завершение даже при отсутствующем pairing-файле. Аналогично падал `cs_install_ipa`.

Теперь обе функции копируют/проверяют входные параметры и выполняют сетевой future на отдельном потоке со стеком 4 МБ, как существующие операции CarrierSIM. Обычное открытие вкладки только показывает интерфейс; проверка запускается кнопкой. Сохранённое ожидание после запроса включения по-прежнему возобновляет только чтение состояния.

Два новых теста вызывают настоящие экспортированные функции из потока со стеком 512 КБ. Подпроцесс изолирует аварийное завершение: до исправления оба теста падают, после него функции возвращают обычную ошибку и освобождаемые строки. Полный набор теперь содержит 70 основных тестов и один тест туннеля. Обе IPA имеют версию 1.2.1 (4).

Физического iPhone в среде сборки нет; подтверждение исправления именно пользовательского вылета требует установки обновления на устройстве. Сопряжение, действительная подпись Apple, доступность служб и системные подтверждения остаются необходимыми. Подпись через iCloud, USB-C между iPhone и мобильный удалённый доступ не добавлены.
