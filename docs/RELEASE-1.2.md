# CarrierSIM 1.2

**ОРИГИНАЛ CARRIERSIM ВЗЯТ ИЗ [IOS-BUNDLES/CARRIERSIM](https://github.com/ios-bundles/CarrierSIM).**

## Новое поведение

На управляющем iPhone можно подписать копию текущего CarrierSIM с помощью P12 и профиля для друга, затем запросить установку через LAN. Для встроенного VPN предусмотрен отдельный профиль расширения; без него создаётся вариант без VPN. Также доступна установка уже подписанного IPA.

Прямая работа с профилем оператора на другом iPhone сохранена: приложение на устройстве друга не требуется. Перед операциями проверяются идентичность цели, сопряжение и состояние восстановления.

Экран режима разработчика читает состояние, запрашивает показ пункта и включение через доступную AMFI-службу. Перед запросом сохраняется ожидание; после перезагрузки выполняется только чтение состояния. Владелец подтверждает включение и код-пароль на своём телефоне. Ошибка службы, `success: false` и неизвестное состояние не показываются как успех. При ошибке InstallationProxy без описания установка также считается ошибкой.

## Проверки

68 основных тестов и один тест туннеля прошли. Обе ARM64 IPA собраны и проверены. Криптографический тест подписывает настоящий ARM64-бандл временным P12, проверяет подпись и обнаруживает изменение бинарного файла. Подробные логи и хеши находятся в [Tests](../CarrierSIM-iOS/Tests/VALIDATION.txt).

## Требования и ограничения

Первый IPA для управляющего телефона нужно подписать вашим сервисом. Для подписи внутри приложения требуются экспортированные P12, пароль и профиль, разрешающий устройство друга. Вход через Apple Account/iCloud и выдача сертификатов отсутствуют.

Службы Apple должны быть доступны через доверенное сопряжение по Wi-Fi. Первоначальная подготовка может потребовать компьютер. USB-C между iPhone и мобильный удалённый доступ не реализованы. Пакет требует iOS 26+, встроенное создание сопряжения через настройки рассчитано на iOS 27.

Физические телефоны недоступны в среде сборки: реальные установки, AMFI, изменение профиля и работа на всех iPhone 12+ ещё не подтверждены. Поэтому выпуск опубликован как prerelease. Изменение профиля не создаёт услугу или покрытие 5G у оператора.
